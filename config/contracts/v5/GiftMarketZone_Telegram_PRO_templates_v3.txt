SECTION: EdgeRank — Production Calculation

Нормализация входных параметров (все в диапазоне 0..1):

S  = Score100 / 100
C  = conf_pct / 100
EP = clamp(expected_profit_pct / 0.30 , 0 , 1)        # 30% = верхний референс
L  = liquidity_score / 100                           # если 0..100
AR = clamp(absorption_30m / 2.0 , 0 , 1)              # 2.0 = сильное поглощение
D  = clamp(depth_score , 0 , 1)                       # уже 0..1
LP = clamp(listing_pressure / 6.0 , 0 , 1)            # 6 = сильное давление

------------------------------------------------------
EdgeRank_raw =
      0.35 * EP
    + 0.25 * S
    + 0.15 * L
    + 0.10 * AR
    + 0.10 * D
    - 0.15 * LP

EdgeRank = clamp(EdgeRank_raw , 0 , 1) * C

EdgeRank100 = round(EdgeRank * 100)
------------------------------------------------------

Интерпретация:

0–30   — нет edge
30–55  — слабый edge
55–70  — рабочий edge (можно публиковать)
70–85  — сильный edge
85+    — топ возможность

------------------------------------------------------
Telegram Publish Gate (PRO):

Публиковать сигнал если:

EdgeRank100 >= 55
AND conf_pct >= 35
AND expected_profit_pct >= 8

Исключение:
STRONG SELL публикуется при:
conf_pct >= 40 AND (LP >= 6 OR AR <= 0.6)

------------------------------------------------------

Пример расчёта:

expected_profit_pct = 14%
Score100 = 81
liquidity_score = 52
absorption_30m = 1.2
depth_score = 0.60
listing_pressure = 1.8
conf_pct = 54

EP = 0.14 / 0.30 = 0.466
S  = 0.81
L  = 0.52
AR = 1.2 / 2.0 = 0.60
D  = 0.60
LP = 1.8 / 6.0 = 0.30
C  = 0.54

EdgeRank_raw =
0.35*0.466 +
0.25*0.81  +
0.15*0.52  +
0.10*0.60  +
0.10*0.60  -
0.15*0.30

= 0.1631 + 0.2025 + 0.078 + 0.06 + 0.06 - 0.045
= 0.5186

EdgeRank = 0.5186 * 0.54 = 0.280
EdgeRank100 = 28

→ Несмотря на хороший Score, низкий Conf уменьшил финальный edge.

======================================================================
APPENDIX: EdgeRank Dynamic Weights by Market Regime
======================================================================
Профиль весов выбирается по market_regime (RISK_ON / MEAN_REVERT / RISK_OFF / PANIC).
Файл для внедрения: edgerank_weights_by_regime.json

Ключевая идея:
- RISK-ON: сильнее вес ликвидности и поглощения (чтобы выбирать “быстро реализуемые”)
- RISK-OFF: сильнее штраф за давление продавцов (LP), и выше вес ликвидности
- PANIC: добавляем бонус импульса VV_norm, иначе упускаем разворотные всплески

Формула неизменна:
EdgeRank = clamp(EdgeRank_raw,0,1) * C
Где EdgeRank_raw = Σ(w_i * x_i) (+ wVV*VV_norm в PANIC)
